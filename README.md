# Node Security Scripts

Scripts en **Node.js** para tareas de seguridad, monitoring y automatización.

## Incluye
- Monitores de procesos y red
- Scripts de análisis básico
- Automatización de tareas de seguridad
- Utilidades para desarrollo seguro

## Requisitos
- Node.js 18+

## Instalación
```bash
npm install
```

## Uso
```bash
node scripts/monitor.js
```

---
Solo para uso ético y autorizado.
